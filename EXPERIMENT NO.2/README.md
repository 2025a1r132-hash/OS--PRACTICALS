Experiment 02: Execution of Basic Bash/Shell Commands in Ubuntu Linux

Aim

To study and execute basic Bash/Shell commands for file-system navigation, file and directory management, text manipulation, and system operations in Ubuntu Linux.

Requirements

- Ubuntu Linux
- Bash Shell
- Terminal

Commands

1. Print Working Directory

pwd

Purpose: Displays the current working directory.

2. List Files and Directories

ls

Purpose: Lists files and directories in the current directory.

3. List Files with Details

ls -l

Purpose: Displays detailed information about files and directories.

4. Change Directory

cd Documents

Purpose: Moves into the Documents directory if it exists.

5. Create a Directory

mkdir OS_Practical

Purpose: Creates a directory named "OS_Practical".

6. Create an Empty File

touch notes.txt

Purpose: Creates an empty file named "notes.txt".

7. Display File Contents

cat notes.txt

Purpose: Displays the contents of "notes.txt".

8. Copy a File

cp notes.txt backup.txt

Purpose: Copies "notes.txt" into "backup.txt".

9. Rename a File

mv notes.txt new_notes.txt

Purpose: Renames "notes.txt" to "new_notes.txt".

10. Remove a File

rm backup.txt

Purpose: Deletes "backup.txt". Use carefully.

11. Display Current Date and Time

date

Purpose: Displays the current date and time.

12. Display Current User

whoami

Purpose: Displays the username of the current user.

13. Display File Permissions

ls -l

Purpose: Shows file permissions, ownership, size, and modification time.

14. Display Help for a Command

man ls

Purpose: Opens the manual page for the "ls" command. Press "q" to exit.

Procedure

1. Open the Ubuntu Terminal.
2. Enter each command one by one.
3. Observe the output displayed on the screen.
4. Create, copy, rename, and list files as described above.
5. Record the actual output and take screenshots.

Expected Output

The commands display directory information, create and manage files, show file contents, and provide basic system information.

Result

Basic Bash/Shell commands for file-system navigation, file management, and system operations were studied and executed in Ubuntu Linux.
