Experiment 01: Installation and Configuration of Oracle VirtualBox and Ubuntu Linux

Aim

To install Oracle VirtualBox, create and configure a virtual machine, and install Ubuntu Linux in a virtualized environment.

Requirements

- Computer or laptop
- Oracle VirtualBox
- Ubuntu Linux ISO image
- Sufficient RAM and free disk space
- Internet connection

Introduction

Oracle VirtualBox is virtualization software that allows us to run an operating system inside a virtual machine. Ubuntu is a Linux-based operating system. This experiment demonstrates how to create a virtual machine and configure Ubuntu Linux.

Procedure

Step 1: Download VirtualBox

Download Oracle VirtualBox from its official website:
https://www.virtualbox.org/

Step 2: Download Ubuntu

Download the Ubuntu Desktop ISO image from:
https://ubuntu.com/download/desktop

Step 3: Create a Virtual Machine

1. Open Oracle VirtualBox.
2. Click on New.
3. Enter the name as Ubuntu Linux.
4. Select the Ubuntu ISO image.
5. Allocate suitable RAM and processor resources according to the computer's capacity.
6. Create a virtual hard disk with sufficient storage.

Step 4: Install Ubuntu

1. Start the virtual machine.
2. Follow the Ubuntu installation instructions.
3. Select the required language and keyboard layout.
4. Complete the installation.
5. Restart the virtual machine when prompted.

Step 5: Verify the Installation

Open the Ubuntu terminal and execute the following commands.

Display system information:

uname -a

Display operating system information:

cat /etc/os-release

Display the current date and time:

date

Display the current working directory:

pwd

Expected Output

- The "uname -a" command displays Linux kernel and system information.
- The "cat /etc/os-release" command displays the installed operating system details.
- The "date" command displays the current date and time.
- The "pwd" command displays the current working directory.

Important Notes

- Allocate RAM and storage according to the computer's available resources.
- Download VirtualBox and Ubuntu only from their official websites.
- Take screenshots of the installation process and terminal output for the practical record.
- Actual output may vary depending on the Ubuntu version and system configuration.

Result

Oracle VirtualBox was configured, and Ubuntu Linux was installed in a virtual machine. The installation was verified using basic Linux commands.
