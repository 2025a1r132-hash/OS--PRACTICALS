Experiment 01: Installation and Configuration of Oracle VirtualBox and Ubuntu Linux

Aim

To install Oracle VirtualBox, create and configure a virtual machine, and install Ubuntu Linux in a virtualized environment.

Requirements

- Computer or laptop
- Oracle VirtualBox
- Ubuntu Linux ISO image
- Sufficient RAM and disk space

Procedure

1. Download Oracle VirtualBox from its official website.
2. Download the Ubuntu Linux ISO image.
3. Open VirtualBox and click on New.
4. Enter the virtual machine name as Ubuntu Linux.
5. Allocate RAM and create a virtual hard disk.
6. Attach the Ubuntu ISO image.
7. Start the virtual machine and follow the installation instructions.
8. Restart the virtual machine after installation.

Commands for Verification

uname -a

cat /etc/os-release

Expected Output

The first command displays Linux kernel information. The second command displays the installed operating system details.

Result

Oracle VirtualBox and Ubuntu Linux are configured and verified in a virtualized environment.
